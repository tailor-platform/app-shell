# Next.js Example

Example AppShell application using Next.js App Router.

## Run

From this directory (only the Next.js app):

```bash
pnpm dev
```

From the **monorepo root**:

```bash
pnpm dev:next
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

To watch **every** example at once via Turbo (uses more RAM), use `pnpm dev:examples` from the repo root instead.
